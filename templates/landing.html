How it works

From question to answer in three steps.

No setup ceremony. Launch the hub, ask anything, and let routing do the rest.

It reads your task

The hub classifies each request as simple, medium or hard — and checks the model's tool and vision needs.

It picks the free model

From 354 live free models, the router chooses the strongest that fits the difficulty tier and your quota.

It answers & learns

First content streams back fast. Every hop is scored, so the hub routes around slow or cold models automatically.

Built for your workflow.

Acurl-compatible gateway means you can swap your existing OpenAI calls to free models in seconds.

Drop-in API

OpenAI-compatible, so it's a one-line change.

Set your base URL to the hub and add any free model. Your existing client code keeps working.

chat on free models — curl
# Point any OpenAI-compatible client at the hub
curl http://127.0.0.1:8787/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "auto",
    "messages": [{"role": "user", "content": "Explain gravity simply"}]
  }'

# model: "auto" → hub picks the best free model for the task
